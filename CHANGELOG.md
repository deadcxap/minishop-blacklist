# Журнал изменений

## В разработке

- На Core с `durable_jobs` версии 2 воркер получает задания об обычных оплатах только при настроенном чате, источниках и включённых уведомлениях об оплате. Изменения настроек применяются со следующего платежа.

- Синхронизация сохраняет неизменившиеся строки и применяет изменения одного источника за транзакцию. До двух загрузок на воркер, ручное обновление подхватывается при ближайшей проверке расписания.
- На Core с `admin_users_table` версии 1 статус и фильтр совпадений доступны в штатном списке пользователей. Сохраняется поддержка Minishop 3.8.5.
- Для регистрации, триала, истечения подписки и пополнения баланса подтверждённое отсутствие совпадения проверяется до записи задания уведомления.

- Публикация пакетов GitHub Actions запускается только при отправке тега версии `vX.Y.Z`. Архив и установочный индекс обновляются в `main` после сборки из отмеченного коммита. [Порядок выпуска](doc/installation.md#публикация-по-тегу)

## 1.0.0

- Столбец «Причины и ссылки» перемещён сразу после «Пользователя» в таблице совпадений.
- Удалены вкладка «Логи Telegram», запись диагностических данных и тестовая отправка. При обновлении отменяются оставшиеся тестовые задания. Обычные уведомления используют сохранённые настройки.

## 0.2.0

- Раздел «Пользователи из blacklist» использует оформление, столбцы, поиск, сортировку и фильтры штатного списка Minishop. Причины совпадения остаются в таблице. Карточка открывается внутри админки с быстрой кнопкой возврата к результатам.
- Кнопка «Обновить списки» запускает внеплановую загрузку сохранённых источников и показывает результат по каждому из них.
- Добавлена вкладка «Логи Telegram». В режиме отладки видны попытки отправки, параметры запроса, ответы Telegram и причины пропуска. Тестовое уведомление проверяет настроенные чат и топик. [Руководство для 0.2.0](https://github.com/deadcxap/minishop-blacklist/blob/v0.2.0/doc/telegram-diagnostics.md)
- Исправлена проверка активации триала для случая, когда Minishop успевает обновить статус подписки до обработки уведомления.
- Добавлен [README](README.md) с обзором плагина, требованиями, установкой и настройкой.

## 0.1.0

- Добавлен плагин для Minishop 3.8.5 с двумя стартовыми источниками. Ссылки редактируются в многострочном поле, а интервал обновления задаётся в часах и по умолчанию равен 24 часам. При сбое загрузки сохраняется последний успешный снимок каждого источника.
- Добавлены раздел «Пользователи из blacklist», вкладка в карточке пользователя и статус в открытом тикете. Для одного Telegram ID отображаются все различающиеся комментарии и ссылки. Показ информации настраивается отдельно для каждого представления.
- Добавлены Telegram-уведомления о регистрации, активации триала, оплате и истечении подписки с настройкой чата, топика и набора событий.
- Добавлена сборка подписанного пакета и публикация стабильных версий через GitHub Actions. [Установка и настройка](doc/installation.md)
- Описаны [возможности будущих версий API Minishop](doc/future-api.md).
