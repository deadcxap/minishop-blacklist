# minishop-blacklist

Чёрный список для **Remnawave Minishop**. Плагин сверяет Telegram ID клиентов с внешними списками, показывает совпадения в админке и предупреждает администратора в Telegram. Совпадение служит подсказкой для проверки. Права клиента и его подписка остаются прежними.

## Возможности

- Два преднастроенных источника и многострочное поле для редактирования списка ссылок.
- Фоновое обновление с настраиваемым интервалом. По умолчанию — каждые **24 часа**.
- Внеплановая загрузка сохранённых источников кнопкой **Обновить списки**.
- Раздел «Пользователи из blacklist», вкладка в карточке клиента и статус в открытом тикете. Показ в каждом месте настраивается отдельно.
- Все различающиеся комментарии по каждому Telegram ID. Иконки рядом с комментариями открывают ссылки в новой вкладке.
- Уведомления в выбранный Telegram-чат или топик о регистрации, триале, оплате и истечении подписки.
- Админский интерфейс на русском и английском языках.

## Совместимость

Версия **1.1.0** проверена на штатном **Minishop 3.8.5 и 3.8.6**. Подписанному пакету нужны Linux x86_64, Python 3.12, Plugin API 1, frontend host API 1 и возможности Minishop `ui_composition` от 3 и `durable_jobs` от 1. Сопоставление доступно для аккаунтов с привязанным Telegram ID.

## Установка и обновление

1. В админке Minishop откройте **Плагины**, выберите установку из репозитория и укажите его адрес. Minishop скачает подписанный ZIP по установочному индексу. [Репозиторий плагина](https://github.com/deadcxap/minishop-blacklist) · [Установочный индекс](minishop-plugin.json)
2. Сверьте открытый ключ издателя, подтвердите установку и включите плагин. Minishop применит пакет в веб-процессе и воркере, после чего начнётся первая загрузка списков. [Открытый ключ издателя](publisher.pub)
3. Откройте **Плагины → Чёрный список → Настройки**. Настройте источники, области показа и уведомления.

Для ручной установки скачайте `minishop-blacklist-<версия>.zip` из вложений релиза и загрузите архив в разделе **Плагины**. При установке из репозитория новые выпуски появляются во вкладке **Обновления**. На доступную сейчас версию указывает установочный индекс. [Все релизы](https://github.com/deadcxap/minishop-blacklist/releases)

## Источники и совпадения

В поле **Ссылки на списки** укажите до 20 публичных HTTPS-адресов, по одному на строку. Интервал обновления задаётся целым числом часов. Новый источник воркер загрузит при ближайшей проверке. Сохраните пустое поле, чтобы прекратить сопоставление.

Списки читаются как текст UTF-8. Каждая запись начинается с числового Telegram ID. После первого `#` можно указать комментарий и ссылки. Пустые строки и строки, начинающиеся с `#`, пропускаются. Пример с вымышленными данными

```text
1000000001 # Повторные нарушения правил https://example.org/report/1
1000000001 # Подтверждённая жалоба https://example.org/report/2
```

В примере у клиента будут видны оба комментария. Одинаковый комментарий из нескольких записей выводится один раз со всеми различающимися ссылками.

В настройках отображаются время последней успешной загрузки, число записей и ошибки по каждому источнику. Чтобы загрузить списки вне графика, сохраните ссылки и нажмите **Обновить списки**. При ошибке используется последний успешный снимок, а устаревшие данные помечаются в интерфейсе. Удалённый источник исключается из сопоставления сразу после сохранения настроек.

## Интерфейс администратора

| Где | Что показывает плагин |
| --- | --- |
| **Пользователи из blacklist** | Таблица с поиском, фильтрами и сортировкой. «Причины и ссылки» идут сразу после «Пользователя». Карточка открывается без перезагрузки, а кнопка возврата ведёт обратно к результатам. |
| **Пользователи** · Minishop 3.8.6 | Столбец и фильтр «Чёрный список». ❌ — найдено совпадение, ✓ — совпадений нет после проверки всех источников, `?` — проверка неполная, `—` — аккаунт без Telegram. Столбец и фильтр включены по умолчанию и управляются одним переключателем в настройках плагина. |
| **Пользователи → карточка клиента → Чёрный список** | Статус проверки Telegram ID, комментарии и ссылки. |
| **Поддержка → открытый тикет** | Статус автора тикета, комментарии и ссылки над редактором ответа. На телефоне в Minishop 3.8.6 блок открывается кнопкой в шапке тикета. |

Выключатели в настройках управляют содержимым этих представлений. На Minishop 3.8.5 пункт меню и вкладка карточки остаются в навигации. Метка в списке тикетов зависит от будущей точки расширения Minishop. [План на случай расширения API](doc/future-api.md)

## Уведомления в Telegram

Укажите числовой **ID чата**, в котором бот Minishop может отправлять сообщения. Для форума можно дополнительно указать **ID топика**. Оставьте поле топика пустым для отправки в чат. При установке уведомления выключены. Флажок **Все события** включает все четыре события.

| Событие | Когда приходит уведомление |
| --- | --- |
| **Зарегистрировался** | Новый клиент с привязанным Telegram ID найден в списке. |
| **Взял триал** | Клиент из списка успешно активировал триал. |
| **Оплатил** | Клиент из списка совершил успешный платёж положительной суммы. Учитываются в том числе пополнение баланса и автопродление. |
| **Истёк** | Воркер Minishop сообщил об истечении подписки клиента из списка. |

В уведомлении есть событие, данные клиента, комментарии и кнопка перехода в карточку. Платный триал может дать два уведомления, если одновременно включены события оплаты и активации триала.
