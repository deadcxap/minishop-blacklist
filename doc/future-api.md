# План на случай расширения API плагинов Minishop

Проверены точки расширения Minishop 3.8.5. Следующие возможности можно добавить в плагин после появления соответствующих контрактов в Minishop.

| Интерфейс | Какой контракт нужен |
| --- | --- |
| Постоянный статус в `/admin/users/{ID}` | Слот в шапке или в общей части карточки с данными текущего аккаунта. Встроенный блок показывает статус, все разные комментарии и иконки ссылок. |
| Красный крестик в списке `/admin/support` | Слот метки строки или карточки тикета, позволяющий загрузить статусы авторов одним запросом. |
| Скрытие пункта меню и вкладки карточки по настройке | Серверный контракт видимости админских представлений из подписанного пакета. Он должен работать после сохранения настроек и для прямого перехода на скрытую страницу. |

Когда Minishop выпустит соответствующие точки, сверить их версии, подключить их по возможности установленного ядра и проверить совместимость со штатными экранами. На Minishop 3.8.5 остаются [доступные сейчас представления плагина](implementation-plan.md#совместимость-с-minishop-385).
